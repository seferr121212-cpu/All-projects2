# Asset licenses — VARDİYA

Up to stage 6 the game contains **no third-party copyrighted music, sound, model, texture or font**.

| Asset | Source | License |
|---|---|---|
| UI font | Godot Engine built-in default font (no file shipped by us) | Ships with Godot (MIT engine license; the default font is OFL-licensed) |
| `packaging/cover.png`, `packaging/banner.png`, `icon.png`, `packaging/icon.png` | Generated by us with a Python script as placeholders. Text rasterised with DejaVu Sans (Bitstream Vera / public-domain-style license, font not shipped) | Own work, placeholder |
| Audio | None. `AudioBus.play()` silently skips missing files under `assets/audio/` | — |
| 3D models (stage 6) | Built in code from boxes and prisms by `scenes/world/prop_kit.gd` (props), `scenes/world/character_body.gd` (characters) and `scenes/world/location_builder.gd` (walls, floor, fire, light shafts). No model files. | Own work |
| Textures (stage 6) | Generated at runtime by `scenes/world/art_kit.gd` from Godot's `FastNoiseLite` (concrete, metal, paint, wood, fabric, plaster; 512 × 512, greyscale, mipmapped). No image files. Soft sprite and vignette are `GradientTexture2D`. | Own work |
| Particles, sky | Godot `CPUParticles3D` and `ProceduralSkyMaterial` with our parameters | Own work |
| `docs/maps/*.png` | Rendered by `tools/render_map.py` | Own work |
| Story text (`data/`) | Original writing for this project | Own work |

Rules for later stages:
- Only CC0 / own work / explicitly licensed assets. Record every file here with source URL and license.
- Textures 512 px by default, max 1024 px. Music OGG Vorbis, SFX WAV/OGG.
